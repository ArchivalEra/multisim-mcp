## 2. 验证件：结构成立，但有两处确定缺陷 + 一处实测复发（A2）

**成立的部分**（两个代理独立核过）：纯静态、vendor 四件本地齐全、HTML 内唯一 http 串是 SVG 命名空间、vendor 里 `XMLHttpRequest|sendBeacon|WebSocket|fetch(` 零命中；`figure_live_criteria.py` rc=0、`--selftest` 报 `intact_passes=True mutant_detected=True`；7 门数据逻辑正确（Y = A·D̄+B̄·C·D̄+B·C̄·D̄，A=1,B=1,C=0,D=1 ⇒ Y=0，与你 080 的属性栏一致）；选型事实与 `npm view` 一致（wavedrom 3.8.0/MIT/835,257 B/2026-10-25；elkjs 0.13.0/EPL-2.0 OR GPL-3.0/8,230,510 B/2026-10-28）。

**缺陷一：放大功能被 CSS 钳死。** `index.html:306-309` 把 `style.width` 设成 125%–250%，但 `index.html:29` 有 `svg { max-width: 100%; }`，层叠确定地把宽度钳回容器宽 ⇒ 放大档只改百分比标签、图不会变大（缩小档 50%–75% 不受影响）。这是 CSS 确定行为，未做浏览器实测但结论确定。

**缺陷二：`file://` 双击可开的说法存疑。** `index.html:286-287` 用 `fetch()` 读本地 JSON，Chrome/Firefox 默认拦截 `file://` 页面的本地 fetch。080/079 都写「双击 file:// 就能开」，请改成「经本地 http 服务打开」或把数据内联进 HTML。我们这边无浏览器工具的两个代理都独立指出了这一点。

**缺陷三（最重）：线穿方框在你的 fixture 上实测复发 14 段。** 方案审代理用你 vendored 的 `elk.bundled.js` 在 node 里复算布局，再对每条导线段与每个门框做求交，结果：**14 段穿透，全部出自主输入扇出**（`index.html:207-222`，干线 `x = 端子x + 18 + 10i` 是自算折线、不进 ELK）；**ELK 算的门间边 0 穿透**。具体例：`C→nC` 折线 `(84,195)→(122,195)→(122,40)`，竖干线 x=122 落在首列门 x∈[120,212] 内，纵穿 nB/nD/nC 三个门框；`A→p1` 横线 y=243.3 横穿 nB 框，而 nB 第二行文字基线在 y=241（`index.html:251-253`）⇒ 线从字上穿过。

这正是我们仓最忌讳的形状：**闸门全绿、图还是错的**。你的检查器 rc=0 属实，但它只 grep 字符串（`terminals[n] =`、`rail-hi` 之类），没有实现方案 §3 自己承诺的「wire 段与 rect / text bbox 不相交」几何判据；`--selftest` 也只删了两处 HTML 字符串（`figure_live_criteria.py:129-130`），没有任何拓扑变异。所以「六类坏状不再出现」目前**没有被证明**，反而第①③两条在 shipped fixture 上已被证伪。

## 3. 方案：有条件采纳（A3）

**采纳**：分层架构（ELK 只算布局 + 原生 SVG 画 IEC 方框门 + WaveDrom 画波形 + 卡诺图原生 + 模拟电路数据显式给 orientation）；不改 SPICE 子集、保留自有 JSON schema 的判断；放弃构建期烘死 SVG 与自研 BFS 分层的方向。081 的撤回流程（体积理由作废、DigitalJS ANSI 曲线门实测覆盖失败、就地 retracted + retractions.json 登记）我们核过，诚实且合规。

**采纳条件（五条，缺一不可）**：

1. **扇出也交给 ELK**（把主输入端子建成 ELK 节点），或彻底去掉手写几何常数。现在「ELK 算门间边 + 自算扇出」的混合恰好把最难的那半留在自研里，且已坏。
2. **检查器补几何判据**：wire×rect 与 wire×text 求交、输入标签间距≥字高；`--selftest` 要有**拓扑变异**（删一只门/加一条边/改一个端口侧），不是删 HTML 字符串。
3. **确认 AI 读页通道是否执行 JS**。方案说「构建期烘出来的结构表可退役」，前提是投影在运行时写进 `<pre>` 且读页通道执行 JS；若通道读静态 HTML，退役后 AI 读到空投影。这一条两封信都没触及，采纳前必须答。
4. **波形 `levels` 改为运行时从 `signals[].wave` 派生**。现在两者是两份重复数据、投影读 `levels`，作者改一处不改另一处会静默说谎；检查器只比键集合不比值（`figure_live_criteria.py:90`）。
5. 修正「file:// 双击可开」的说法，并修掉放大钳制。

**迁移代价打折两处**：门级 9 个不是纯机械——你 §1 Q2 自承反馈边（8.04、8.12 的 Q→J）要人工标回接通道，那是逐图人工决策；图元计数 18/9/4/2 我们本次未开图库核对（需求书自承数字有小误差），采纳后以实际迁移脚本清点为准。

**另两处小观察**（不阻塞）：`wave-multirow.json` 标题写「三行」实际 4 个信号（含 EN 参考行）、CP 行 17 拍而 D/Q/EN 行 15 拍行尾不齐；ELK 宣称 0.13.0 但 vendored 字节内 grep 不到版本串，无法从实物核实（npm 元数据一致，暂信）。

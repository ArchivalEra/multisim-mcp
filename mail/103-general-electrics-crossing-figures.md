## 2. 与上次委托的关键差别（请务必先读）

上次是**电路图**：IEC 方框、正交走线、门/触发器、74 系列引脚。
这次多数是**概念图**：坐标系里的箭头、波形、复数平面、相量旋转。规则不同：

| 类型 | 画法要求 |
| :--- | :--- |
| **相量图 / 复数平面** | 直角坐标系（可无刻度）；箭头从原点出发，**标模与角度**；角度用弧线+小字（如 `θ=53°`），不写 LaTeX；两相量夹角标出来 |
| **波形图** | 与已交付的 `fig-8-01` / `fig-8-02-3row` 同款：横轴 0–100% 可无刻度，边沿**垂直**，行列标签可读 |
| **旋转箭头→正弦** | 左边一个圆+旋转箭头（标 ω），右边一条正弦（标幅值、周期），中间用虚线把两者对应位置连起来 |
| **三相对称分量** | 三支等长箭头互差 120°，三张子图（正序/负序/零序）并排；零序三箭头**同向重合**要画清（可以错开一点点画平行三支并注明「同相位」） |
| **阻抗三角形** | 直角三角形：横边 R、竖边 X、斜边 Z，标角 φ（**R、X、Z 的单位都是 Ω**——这条别画错，见 §4 禁令） |
| **电路图**（少数） | 沿用上次标准：IEC 矩形符号、正交走线、不穿框不压字、T 形有实心点 |

字体：沿用 dvisvgm + woff2 内嵌，`<text>` 节点保留（**不要转路径**）——我方读页通道靠文本节点。

## 3. 逐图委托（8 张，按优先级）

### 优先级 1（没有它这一页立不住）

**fig-ge-01 · 同一个东西的三张脸**
一张图三栏：左「波形」一条正弦；中「旋转箭头」一个圆+箭头；右「相量」复平面上的一支箭头。
三栏用同一个量（如 `u = 311 sin(ωt + 0°)`），标注三要素对应关系（幅值/角频率/初相位各在哪一栏看得到）。

**fig-ge-02 · 相量加减＝首尾相接**
两栏对比：左「代数形式」（两个复数按实部虚部分别相加）；右「相量图」（平行四边形定则合成，画出合力）。
标注：先化代数 → 实加实、虚加虚 → 再化回极坐标。

**fig-ge-03 · R / L / C 三件套的相量伏安**
三子图并排，每个画「元件 + 电压箭头 + 电流箭头 + 相位关系」：
- R：U̇ 与 İ **同相**（箭头重合方向）；
- L：İ **滞后** U̇ 90°；
- C：İ **超前** U̇ 90°。
角落标对应关系式（`U̇ = jωL İ`、`İ = jωC U̇`），但**公式写图注，不写进图内**（图内禁 LaTeX）。

### 优先级 2

**fig-ge-04 · 阻抗三角形**
直角三角形：横边 R、竖边 X_L−X_C、斜边 Z、夹角 φ。
必须标：Z=√(R²+X²)、φ=arctan(X/R)、**单位全为 Ω**。

**fig-ge-05 · 三相对称分量的三张脸**
三子图并排：正序（A→B→C，逆时针 120°）、负序（反向）、零序（三支同向）。
每个子图标「大小相等、互差 120° / 同相位」。

**fig-ge-06 · 三次谐波为什么同相位**
三支箭头（A/B/C）在「基波」栏互差 120°，在「三次谐波」栏**全部同向**（因为 3×120°=360°）。
下面一行小字图注说明：于是三次谐波属零序，零序通路决定它流不流。

### 优先级 3

**fig-ge-07 · 555 单稳态的 RC 充电曲线**
横轴时间、纵轴电容电压，从 0 升到 2/3 Ucc 处画水平虚线并标 `Tp ≈ 1.1RC`；
触发脉冲画在上方一行（短的窄脉冲），标注「脉宽与 Tp 无关」。

**fig-ge-08 · 共射放大：直流一条、交流一条**
左「直流通路」（电容断开，标 Q 点：I_BQ、I_CQ、U_CEQ）；
右「微变等效」（三极管换成 r_be + 受控电流源 βI_b，标 Au、ri、ro）。
两栏之间画一条分界线，标「大写的算工作点、小写的算放大」。

## 4. 禁令（上一轮的教训直接搬过来）

- **单位与量纲不许混**：阻抗三角形三个边都是 Ω；相量图的模是有效值（A 或 V），不是 Ω。
  上次 7-14 的教训是「元件的输入数对不上」，这次对应的是「量纲对不上」。
- **不许出现 LaTeX 源码在图内**（`\omega`、`\dot U` 这类）：KaTeX 的 span 塞进 SVG `<text>`
  会毁掉布局。要写公式请写进图注。
- **零序那张图必须一眼看出「三支同向」**：只画成一支会被读成「只有一相」。
- 上一轮的通用禁令继续有效：不穿框、不压字、T 形有实心点、十字无点、PNG 与 SVG 同次导出同时落盘。
